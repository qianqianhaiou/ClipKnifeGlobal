# 素刀（ClipKnife）— Windows 本地 AI 素材管理与智能搜索工具

[English](./README.md) | **简体中文**

> 记得画面，就从画面开始找。让已有素材继续创造价值。

**素刀（ClipKnife）是一款面向创作者的 Windows 本地素材管理与 AI 智能搜索工具。** 它帮助你统一管理分散在文件夹和硬盘中的图片、视频与音频，用自然语言描述或参考图片查找图片和视频分镜，也能在完成语音转写后，按说话内容定位音视频片段。

无论你是视频剪辑师、内容创作者，还是积累了大量素材的个人用户，素刀都能帮助你查找、预览和整理已有素材，让它们在下一个项目中得到复用。

[国际官网](https://clipknife.net/) · [国内官网](https://clipknife.cn/)

## 素刀能解决什么问题？

| 你遇到的问题 | 素刀如何帮助你 |
| --- | --- |
| 记得画面，却想不起文件名。 | 用一句话描述画面，在自己的素材库中查找相关图片和视频分镜。 |
| 素材散落在多个文件夹和硬盘里。 | 将图片、视频和音频纳入同一个可搜索的素材库，减少逐个翻找目录的工作。 |
| 视频太长，找一个镜头要来回拖动。 | 浏览视频分镜，预览相关片段，导出选中的镜头继续剪辑。 |
| 记得录音或视频里说过的一句话。 | 开启对应的语音转写并完成处理后，搜索说话内容，定位相关音视频时间段。 |
| 手里有参考图，想找相近的素材。 | 使用以图搜图，在素材库中查找视觉相似的图片和视频分镜。 |
| 项目结束后，好素材就被遗忘了。 | 将素材和分镜整理到分组中，方便回看、筛选和再次使用。 |

## 素刀适合谁？

- **视频剪辑师与影视创作者**：查找空镜、参考镜头和可复用的视频片段。
- **短视频与自媒体创作者**：整理不断积累的拍摄片段、录音和创作素材。
- **营销与电商内容创作者**：管理产品图片、活动视频和视觉参考资料。
- **摄影师与独立创作者**：除了文件名，也希望按照画面内容找到需要的素材。

## 从素材积累到下一次创作

1. **添加素材。** 选择存放图片、视频和音频的文件夹或硬盘。
2. **等待素材库准备完成。** 素材就绪后再开始搜索；需要按说话内容查找时，先开启语音转写。
3. **描述画面，或提供参考图。** 查找相关图片、视频分镜，也可以检索已完成转写的语音内容。
4. **确认内容，再投入使用。** 预览原始素材，将有用的结果整理到分组，或导出选中的视频片段继续剪辑。

### 用你记得的内容搜索

不用先猜文件名，可以尝试这样描述：

- “海边日落，海浪拍打岸边礁石。”
- “红色产品包装的近景特写。”
- “阳光穿过树林，照亮林间小径。”

这些描述展示的是搜索方式。实际结果取决于素材库中已有的内容和处理完成情况，使用前请预览确认。

## 常见问题

### 素刀可以按画面内容搜索本地视频吗？

可以。素材库准备完成后，你可以用画面描述或参考图片查找相关视频分镜，再预览对应片段，判断是否适合当前项目。AI 搜索可能遗漏细节或出现不准确的匹配，结果需要人工确认。

### 素刀可以搜索音频或视频里的说话内容吗？

可以。开启对应的语音转写选项并完成处理后，就能搜索转写文本，定位关联的音视频时间段，适合回找访谈、口播和其他语音记录中的内容。

### 素刀是视频剪辑软件吗？

素刀专注于素材的查找、整理、预览和复用，帮助你完成剪辑前的素材准备。视频编排、精剪和最终成片导出，仍在你使用的剪辑软件中完成。

### 素刀会上传我的素材吗？

核心的本地建库、搜索、视频分镜和语音转写不会向素刀公网服务上传原始素材。可选的外部 AI 服务可能接收你选择的内容；主动开启局域网共享后，素材会在已授权设备之间传输。激活、许可验证、更新及其他在线产品服务需要联网，各项功能的数据范围请查看官网说明。

### 素刀支持哪些操作系统？

素刀目前面向 Windows x64。具体系统要求、地区下载开放情况及可选功能的使用条件，请以官网当前说明为准。
